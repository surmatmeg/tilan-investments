# Tilan Investments Website

Official web application for **Tilan Investments**, offering real estate services, general supplies, and strategic consultancy.

## Features
- **Real Estate**: Property offerings, structural developments, and land advisory.
- **General Supplies**: Commercial sourcing, logistical support, and institutional supply chains.
- **Consultancy**: Business strategic planning, project evaluation, and operational insight.
- **Interactive Rating & Survey**: Dynamic feedback rating module for site visitors.
